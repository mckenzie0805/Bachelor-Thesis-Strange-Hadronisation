# Angular Correlations

This directory contains ROOT macros used to study angular correlations between strange hadrons produced in proton–proton collisions. Correlation analyses provide insight into particle production mechanisms, jet structure, and hadronisation dynamics as a function of event multiplicity.

## Files

- `plot_correlations_2D.C` – Produces two-dimensional angular correlation distributions in Δη–Δφ space for strange hadron pairs.

- `correlations_multiplicity_classes.C` – Analyses angular correlations in different charged-particle multiplicity classes, enabling comparison of correlation structures across event activity.

## Notes

- Correlations are constructed using azimuthal angle (Δφ) and pseudorapidity (Δη) differences between particle pairs.
- The analysis focuses on strange baryon correlations as probes of hadronisation mechanisms.
- Multiplicity-dependent correlation patterns are used to study collective and jet-related effects.
- These macros support the angular correlation results presented in the Bachelor thesis.
